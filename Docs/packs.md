# Asset packs

My personal Kura library, published as `.kurapack` files you can import whole. Every pack carries its own collections, so importing one files its materials into the same tree they had here instead of dropping them all into *Unsorted*.

**33 packs · 58.11 GB · snapshot of 2026-08-23**

Source material is CC0, from [Poly Haven](https://polyhaven.com) and [ambientCG](https://ambientcg.com). The material instances, master material and material functions are mine, MIT-licensed like the plugin. Nothing here needs attribution, though both sites deserve yours.

## Before you start

New to Kura? Import [`Kura_Starter.kurapack`](https://github.com/Yashashin/Kura/releases) from the latest release first. It is 56 MB and carries one material instance plus the master material, functions and textures every pack on this page shares. Once it is in, any pack you import afterwards will show those 25 assets as *Identical (Skipped)* — that is the deduplication working, not an error.

Then, for each pack you want:

1. Download it. Links resume, so a dropped connection is not a restart.
2. In Kura, **⋮ → Library → Import Package**, pick the file.
3. Leave the **Collection** dropdown on *Use the package's collections* to get the categories below, or point it at one of your own collections to file everything flat there instead.

Importing unpacks to a staging area first, so make sure you have roughly **twice the pack's size** free on the drive holding your library. The largest pack here is 2.93 GB.

## As-is

These are a snapshot of my own library as it stood on 2026-08-23, published because a library with something in it is easier to judge than an empty one. They are **not a maintained product**: I do not plan to update them, re-export them for future engine versions, or take requests or bug reports about the materials themselves. Issues with *Kura* — the plugin — are always welcome.

The packs were exported from Unreal Engine 5.7. A `.kurapack` saved by a newer engine than yours is refused on import, so a 5.7 pack works in 5.7 and 5.8.

*Materials* counts what you actually browse and import — the material instances. *Assets* adds the textures, functions and master material they depend on, which Kura carries along so a pack is never a broken subset. Both columns overlap between packs on purpose: a material that belongs in two categories ships in both, and every pack repeats the shared master and functions. Import as many as you like — Kura stores each one once, which is why the per-pack numbers add up to more than the totals above.

## Checksums

Kura hash-verifies every file inside a package on import, so a corrupted download fails cleanly without touching your library. To check a download before that, save the block below as `SHA256SUMS` next to the files and run `sha256sum -c SHA256SUMS`, or on Windows `Get-FileHash <file> -Algorithm SHA256`.
